# CLI Calculator

A simple command-line calculator built in Python that supports basic arithmetic, recursive power and factorial operations, and persistent calculation history.

## Features

- Menu-driven interface for arithmetic operations
- Addition, subtraction, multiplication, and division
- Recursive power and factorial functions written from scratch
- History saved to a local text file between runs
- Friendly error handling for invalid input and division by zero

## How to run

```bash
python calculator.py
```

## Example menu

```text
CLI Calculator
1. Add
2. Subtract
3. Multiply
4. Divide
5. Power
6. Factorial
7. View History
8. Clear History
9. Exit
```
